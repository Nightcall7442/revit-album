# Чек-лист приёмки альбома

## Автоматически (`sda.py build` → qa.json; выдача только при 0 ошибок)
| код | что ловит | уровень |
|---|---|---|
| TEXT_OVERLAP | надписи/размеры перекрываются (по реальным глифам) | ошибка |
| TEXT_ON_WALL | тёмный текст на тёмной заливке (стена) | ошибка |
| TEXT_IN_STAMP / TEXT_OUT_FRAME | текст в штампе / за рамкой | ошибка |
| VIEWPORT_OVERLAP / TABLE_ON_DRAWING | видовые экраны / таблицы наезжают на чертёж | ошибка |
| CONTENT_CLIPPED | надпись или размер обрезаны видовым экраном | ошибка |
| COLUMN_OVERFLOW | правая колонка не помещается | ошибка |
| TEXT_AT_VP_EDGE, LINE_THROUGH_TEXT | текст у края экрана, линия через текст | предупреждение |
| данные (validate) | геометрия, привязки, высоты, развёртки, двери, полы, потолки, модули | см. `sda.py validate` |

## Глазами — каждый лист (`png/sNN.png`)
**Общее:** номер и название листа = ведомости листов; масштаб в штампе = масштаб вида; лист не пустой и не
переполнен; нет «висящих» подписей (подпись рядом со своим объектом); подписи читаются без поворота листа (снизу
или справа); единый стиль шрифтов.

**Обмерный план:** четыре стороны цепочек; проёмы с размерами и низом окон; чистовые размеры каждого помещения;
Н до плиты; толщины несущих стен; перегородки только пунктиром.

**Перегородки:** каждая перегородка привязана к несущим стенам с двух сторон; проёмы в перегородках с размерами
ш×в; ведомость: длина, высота, площадь, объём кладки.

**Мебель:** позиции на своих предметах, спецификация совпадает с планом (количество!), двери не бьют в мебель.

**Полы:** раскладка от знака, направление доски, стыки в створе дверей, площади = помещения + проёмы (примечание о
разнице), гидроизоляция в мокрых зонах.

**Потолки:** типы и отметки в каждом помещении, размеры коробов/ниш, выноски узлов ведут на лист «Узлы».

**Освещение:** привязки светильников без шума (нет 15/18 мм), споты на треке не привязываются, линии управления от
выключателя к группе, клавиши а/б/в, таблица выключателей = план.

**Розетки:** высота и группа у каждой точки, подписи внутри помещения, нет обычных розеток в санузле, ЩК с отметкой.

**Сантехника:** нумерация выводов = ведомость, высоты, трапы, привязки от стен.

**Развёртки:** вид из помещения (не зеркально), отметки от пола, размеры модулей кратны 5, фартук/плитка, выводы,
двери/окна на своих местах; план санузла с маркерами развёрток.

**Ведомость проёмов:** схемы открывания по ГОСТ (основание — петли), количество = план, примечания о спорных проёмах.

## Вопросы к заказчику (не исправлять молча)
Конфликты дверей и мебели, полотно шире проёма, отсутствующие высоты, нестандартные решения из модели — перечислить
в итоговом сообщении с номерами листов.

## Проектное предложение (если `report.md` его содержит)
- Свет: равномерная сетка, ничего над шкафами; выключатель у каждого входа со стороны ручки; у санузла — снаружи.
- Розетки: у кровати, ТВ, на кухне над столешницей — есть; нет розеток в откосах, за шкафом, над изголовьем — кондиционера.
- Сантехника: выводы у каждого прибора, горячая слева, трап в поддоне.
- Всё это перечислено заказчику как предложение, а не как его решение.

## Мебель индивидуального изготовления (ведомость и эскизы)
- Каждое изделие сцены, которое делает цех, есть в ведомости; покупные — `skip` в `item_overrides`; количество
  совпадает с планом мебели (марки «эскиз М-N» в спецификации плана).
- На эскизе: главный вид, вид слева справа от него, вид сверху под ним — один масштаб; размеры реальные (не
  бумажные), Ø у круглой столешницы, уровни полок / сиденья, деления по ширине; размерные числа не налезают.
- Материалы — по элементам (столешница / опора, обивка / каркас, корпус / полки / подсветка / задняя стенка);
  «по визуализации» допустимо только там, где ни модель, ни дизайнер материала не дали.
- Виды без артефактов: нет треугольников через всё изделие (битые грани сцены), нет «дыр» в гранях. Самопроверка
  рендера (RENDER_GARBAGE / RENDER_EMPTY в отчёте) ловит это сама; RENDER_HEALED — агент уже вычистил деталь.

## Короба, полы, отделка, светильники, развёртки зала (1.4)
- План перегородок: у каждого подвесного унитаза короб инсталляции (верх не выше низа окна), облицовки колонн,
  короба для стояков, каркас стойки, основание скамьи — с выносками «К-n …, h=…» и в ведомости.
- План пола: зоны и форматы как в модели (цвет на тип, сетка плитки), площади без коробов; формат из имени
  материала, отличный от модели, — в решениях «подтвердить».
- Отделка: ни одной плитки на стене, которой нет в модели; материалы названы по текстурам.
- План освещения: люстры (с диаметром) и бра на месте; связи — короткие, привязки — по рядам.
- Стены зала с вывесками / бра / встроенной мебелью — развёртки со схемой; 3D-вид — модели, не кубики.
