# Импорт сцены 3ds Max (.max) без 3ds Max

`python3 sda.py import-max "scene.max" work/imp [--units cm] [--cut 1100] [--floor 0]`

Читает .max напрямую (парсер io_scene_max, GPL-2.0+, в `scripts/importers/max_lib`). Сцена ~1 ГБ — около минуты.

## Что получается
- `inventory.md` — классы объектов, единицы сцены (угаданы по высоте этажа: см/мм/м/дюймы), список объектов, чью
  геометрию нельзя прочитать напрямую.
- `inventory.json` — все узлы: имя, класс, модификаторы, слой, материал, bbox в мм, параметры примитивов
  (`prim_mm`: Plane 0=length (Y), 1=width (X); Box 0=length, 1=width, 2=height), `footprint` примитива в плане.
- `plan_cut.png` (разрез на +1100), `plan_floor.png` (+250), `plan_ceiling.png` (под потолком): чёрное — сечения
  мешей, синий пунктир — контуры Plane/Box с именами, красные — имена мешей; сетка 1 м, координаты сцены в мм.
- `sections.json` — отрезки сечений по объектам (для точных координат).
- `draft_project.json` — заготовка (уровни, кандидаты стен из высоких тонких боксов/мешей с `check: true`).

## Точная геометрия: выгрузка из 3ds Max (рекомендуется всегда)
В 3ds Max открыть сцену → Scripting → Run Script → `scripts/max/sda_export.ms`. Рядом со сценой появятся
`<сцена>.sda.json` и `<сцена>.sda.bin` (сцена не меняется). Их положить рядом с .max (или в ту же папку / архив
на сайте) — импорт возьмёт меши ПОСЛЕ всех модификаторов (Edit Poly, Symmetry, FFD, Shell, FloorGenerator),
точные единицы, флаги «скрыт / не рендерится» (такие объекты в проект не идут). Сверка `audit` тогда проверяет
альбом по геометрии, вычисленной самим 3ds Max.

## Без выгрузки: что агент вычисляет сам (L-099)
- Перемещения вершин Edit Poly на вершинах примитива Box / Plane (1 сегмент) — повторяются точно; сдвиг объекта
  целиком — тоже. Срезы, соединения, отделение и удаление граней, сглаживание — форма не выходит за прочитанную.
- Всё остальное (вершины двигали после смены топологии, Symmetry, FFD, Shell, Bend…) — `geom: unknown` в
  inventory.json: такой объект в альбоме помечается «не проверено», сборка получает статус `audit_errors`
  (не выдавать), пока нет выгрузки 3ds Max.

## Ограничения (важно)
- **Без выгрузки модификаторы вычисляются частично** (см. выше). Толщина и наружная грань стен модели — как
  нарисовал визуализатор: план образмеряется в чистоте от граней помещений (L-103).
- Editable Poly / Editable Mesh читаются полностью (мебель, сантехника, двери MDoor, окна).
- Источники света (CoronaLight и др.) дают положения светильников; камеры/хелперы игнорируются.

## Как превратить в project.json
1. Найти на `plan_cut.png` контур квартиры (синие Plane стен). Выбрать начало координат: пересечение осей 1/А
   (центр левой нижней несущей стены) — все координаты сдвинуть так, чтобы оно было (0,0).
2. Стены: по каждому Plane/Box стены — `rect` (по footprint) или `a,b,t` по оси; `source` = имя объекта.
   Проёмы в модели часто вырезаны ProBoolean: проём = разрыв между стенами или операнд Box (см. inventory: Box…).
3. Двери/окна: объекты MDoor*, Window*, Door* — центр, ширина по bbox; полотно/коробка — в `leaf`, `frame`.
   Сравнить полотно с проёмом (урок L-021).
4. Помещения: seed в каждом; где нет стены — `separations`.
5. Мебель/сантехника: bbox или сечение `plan_floor` → `poly`, `kind` по имени (bed, sofa, wc, basin…).
6. Свет: CoronaLight → точки (`spot`, `chandelier`…), группы по помещениям; треки/линейные — по геометрии.
7. Потолки: `plan_ceiling.png` — короба, ниши, теневые швы → `ceilings.zones`.
8. Нормализовать (кратно 5 мм, модули, зазоры) и `sda.py validate`.
