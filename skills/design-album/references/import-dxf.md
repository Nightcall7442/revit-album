# Импорт плана DWG / DXF

`python3 sda.py import-dxf plan.dxf work/imp [--window x0,y0,x1,y1] [--units mm]`

DWG конвертируется автоматически, если в среде есть ODA File Converter (ezdxf odafc) или LibreDWG `dwg2dxf`;
иначе попросить у заказчика «Сохранить как → DXF 2013» (AutoCAD, nanoCAD, BricsCAD, ZWCAD).

## Что получается
- `layers.md` — слои с количеством объектов и догадкой роли (стены, перегородки, двери, окна, размеры, оси, текст);
  список отдельных чертежей в пространстве модели (план, разрезы, фасады) — берётся крупнейший, иначе `--window`.
- `plan.png` — выбранный чертёж с сеткой 1 м и координатами.
- `texts.json` — все тексты окна (названия помещений, площади, марки) с координатами в мм.
- `inserts.json` — вставки блоков (двери, окна, мебель, сантехника) с позицией, поворотом, масштабом.
- `draft_project.json`:
  - стены — замкнутые полилинии / штриховки слоёв стен (`existing`) и перегородок (`new`), дубликаты убраны;
  - **проёмы** — разрывы между торцами стен (≤ 2600 мм) превращены в короткие стены-перемычки `ПРn` с проёмом;
    наружные → `window`, внутренние → `door` (все с `check: true` — балконные и входные двери уточнить);
  - помещения — по текстам с названиями (seed в точке текста), мокрые — по названию.

## Доработка черновика
1. Сдвинуть начало координат в пересечение осей 1/А; задать `grid`.
2. Проверить каждую стену с `check`, роль (`existing`/`new`), объединить мелкие куски.
3. Проёмы: тип, марка, высота, низ окна, `swing` и `hinge` по дуге двери на плане, полотно.
4. Помещения: уникальные имена, `cls`, `separations` там, где нет стен (кухня-гостиная).
5. Если стены нарисованы отрезками (две параллельные линии) — замкнутых контуров нет: перечертить стены по
   `plan.png` (rect по размерам), координаты брать из `texts.json`/размеров.
6. `sda.py validate` → 0 ошибок.
