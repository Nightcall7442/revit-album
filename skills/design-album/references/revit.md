# Передача в Revit

`python3 sda.py revit work/project.json work/revit` →
- `revit_build_model.py` — для pyRevit / RevitPythonShell;
- `<объект>_Revit.dyn` — Dynamo с движком PythonNet3 (Revit 2025–2027);
- `<объект>_Revit_CPython3.dyn` — Dynamo с CPython3 (Revit 2022–2024).

## Что строится
Уровень, типы стен «АР_Стена наружная/несущая N», «АР_Перегородка N» (однослойные по толщине), стены по осям на
высоту до плиты, оси, двери/окна — типоразмеры по маркам (ширина, высота, низ окна), ориентация дверей по
`swing`/`hinge`, помещения (номер, имя) по seed + линии разделения, план 1:50, два разреза, спецификации
(экспликация, двери, окна) и листы. Непрямоугольные стены (`poly`) не передаются — о них пишется в консоль.
Короба (`box`) не передаются.

## Инструкция пользователю
1. Revit → новый проект из архитектурного шаблона (мм). Загрузить хотя бы одно семейство двери и окна
   (Вставка → Загрузить семейство), если шаблон пустой.
2. Управление → Dynamo → Открыть `.dyn` (выбрать файл под свою версию) → Запуск. В узле «Журнал построения» — отчёт.
   Либо pyRevit / RevitPythonShell → выполнить `revit_build_model.py`.
3. Повторный запуск — только в чистом проекте (иначе стены продублируются).

## Проверка без Revit
`tests/test_revit.py` прогоняет сгенерированный скрипт на поведенческом макете Revit API (`tests/mock_revit.py`):
количество стен/проёмов/помещений, площади, ориентация дверей. Сломать генератор и не заметить нельзя.

## Действия на компьютере пользователя
Только с явного разрешения пользователя (запрос доступа к приложению). Без доступа — передать файлы и инструкцию.
