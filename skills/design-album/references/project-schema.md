# project.json — единственный источник правды

Все листы, ведомости, Revit-модель и проверки строятся из одного файла. Ничего не рисуется «руками» на листе:
нужно изменить чертёж — меняется project.json и альбом пересобирается.

**Единицы:** миллиметры. **План:** x вправо, y вверх; начало координат — пересечение осей 1/А (обычно
внутренний угол или ось наружной стены). **Высоты:** от чистого пола ±0,000.
Полные рабочие примеры: `examples/urgench-apartment/project.json` (квартира 46 м², 19 листов) и
`examples/studio-minimal/project.json` (минимальный проект — шаблон для нового).

Обязательные разделы: `meta`, `levels`, `walls`, `rooms`. Остальные — по мере данных; лист без данных не выпускается.

---

## meta
| поле | пример | где видно |
|---|---|---|
| `title` | `"ДИЗАЙН-ПРОЕКТ\|ИНТЕРЬЕРА КВАРТИРЫ"` | обложка, `\|` — перенос строки |
| `object` | `"Дизайн-проект интерьера квартиры"` | штамп |
| `place` | `"Узбекистан, город Ургенч."` | штамп, обращение |
| `studio`, `stage`, `year`, `country`, `tagline` | | обложка, штамп |
| `album`, `cover_footer` | | обложка |
| `letter` (список абзацев), `letter_title`, `signature` | | лист «Обращение к заказчику» |
| `logo`, `logo_transparent` | путь к PNG (относительно project.json) | штамп / обложка; по умолчанию логотип Space Design Studio |
| `code` | `"КВ-2026-АР"` | номер проекта в Revit |
| `questions` | `["Д-4: подтвердить проём…"]` | «Вопросы к заказчику» на листе «Общие данные» (+ конфликты из проверки данных) |

## levels
`{"floor": 0, "ceiling": 2800, "slab": 3200}` — чистый пол, низ основного потолка, низ плиты.

## grid (оси)
`{"x": [["1", 0], ["2", 3620]], "y": [["А", 0], ["Б", 3070]]}` — имя и координата. Оси — по центрам несущих стен.

## walls
```json
{"id": "С1", "kind": "existing", "rect": [-200, -200, 200, 6220], "a": [0, 0], "b": [0, 6020], "t": 400,
 "source": "Plane001", "material": "..."}
```
- `kind`: `existing` (несущие / существующие), `new` (возводимые перегородки), `box` (короб инсталляции и т.п.).
- геометрия — одно из: `rect` [x0,y0,x1,y1] (предпочтительно), `poly` [[x,y],...], или `a`,`b`,`t` (ось + толщина).
- `a`,`b` — ось стены (для Revit: стена строится по оси); если не заданы — берутся по центру `rect`.
- `material` — для ведомости перегородок; `source` — откуда взято (имя объекта 3D-модели / слой DXF).
- Проёмы **не вырезаются** в стенах: стена цельная, проём — отдельная запись в `openings`.
- Стены без стен («горловина», открытый проём) — просто разрыв между двумя стенами.

## openings
```json
{"id": "Д-1.1", "mark": "Д-1", "kind": "door", "wall": "С6", "c": 5040, "w": 1200, "h": 2200, "sill": 0,
 "room": "Прихожая", "swing": [0, -1], "hinge": "min", "leaf": 921, "hinge_at": 4580, "frame": 66,
 "steel": true, "existing_leaf": true}
```
- `kind`: `window` | `door` | `balcony` (балконная дверь) | `passage` (проём без заполнения).
- `c` — центр вдоль стены (x для горизонтальной стены, y для вертикальной); `w`,`h` — проём в чистоте; `sill` — низ.
- `swing` — вектор, куда открывается полотно (в сторону помещения); `hinge`: `min`/`max` — петли со стороны меньшей/большей координаты.
- `leaf` — ширина полотна; `existing_leaf` — дверь показывается на обмерном плане; `steel` — входная металлическая.
- `room` — помещение для ведомости.

## opening_types
По марке: `{"Д-1": {"oboz": "ГОСТ 31173-2016", "name": "Блок дверной стальной…", "note": "…", "leaf": 921,
"style": "steel|glass|door", "block_h": 2090}}` — ведомость заполнения проёмов и схемы.

## separations
`[[[x,y],[x,y]], …]` — невидимые границы помещений там, где нет стены (кухня-гостиная, коридор-спальня).

## rooms
```json
{"num": "1", "name": "Прихожая", "seed": [4830, 4900], "cls": "circulation", "ceiling_type": "Т1",
 "ceiling_level": 2800, "wall_finish": "О2", "wall_split": {"О2": 14.57, "О1": 3.91}, "label": "Санузел|совм."}
```
- Контур помещения вычисляется: внутренность здания минус стены, разрезанная `separations`; `seed` — любая точка внутри. Можно задать `poly` вручную.
- `cls`: `living` | `kitchen` | `wet` | `circulation` (цвет схемы, гидроизоляция, отделка, развёртки санузлов).
- Имена уникальны (нужно для ссылок мебели, полов, развёрток).

## furniture
`{"name": "Кровать", "kind": "bed", "room": "Спальня", "poly": [[x,y],...], "head": "W"}`
`kind`: bed, nightstand, wardrobe, cabinet, shoe_cabinet, tv_stand, tv, sofa, armchair, table, chair, rug,
kitchen_base, kitchen_upper, fridge, sink, hob, shower, bath, wc, basin, washer, mirror, rail. Одинаковые name+размер
объединяются в одну позицию спецификации. `head` — изголовье кровати (W/E/S/N).

## lighting
`{"kind": "spot", "x": 2820, "y": 3110, "group": "Коридор"}`; линейные (`track`, `linear`, `led`, `track_rect`)
имеют `x2`,`y2`. kinds: spot, spot_ip44, spot2, spot2_ip44, surface, chandelier, pendant, track, track_rect,
track_spot, linear, led. `lighting_spec` — словарь «kind → точное наименование» для спецификации.

## switches
```json
{"id": "В1", "x": 5740, "y": 5820, "h": 900, "wall": "Y-", "keys": 2, "room": "Прихожая",
 "controls": [{"key": "а", "group": "Прихожая", "kinds": ["spot2"], "desc": "споты прихожей"}], "pass_through": false}
```
`wall` — нормаль стены, на которой стоит изделие (направление в помещение): `X+` (стена слева, смотрит вправо),
`X-`, `Y+`, `Y-`. Точка — на чистовой поверхности стены (проверяется).

## sockets / panel / circuits
`{"kind": "Р2", "x": 200, "y": 650, "h": 600, "wall": "X+", "group": "3", "note": "у кровати"}`;
kinds: Р, Р2, РВ (IP44), Р32, ТВ, LAN, КОНД, БРА, ВЫВ. `panel`: `{"name": "ЩК", "x", "y", "w", "wall", "bottom"}`.
`circuits`: строки таблицы групп `[["1", "АВ 1P C10", "ВВГнг(А)-LS 3×1,5", "Освещение…"], …]`.

## plumbing
`{"kind": "ХВС|ГВС|К50|К110", "x", "y", "h", "fixture": "Раковина"}` — точка на стене (у трапа — в полу, h=0).

## floors
```json
{"id": "П1", "material": "Паркетная доска…", "pattern": "plank|tile", "plank": [1300, 160], "along": "y",
 "origin": [200, 200], "tile": [600, 600], "rooms": ["Спальня"], "polys": [[[x,y],…]], "layers": "состав пола",
 "reserve": 0.1}
```
`polys` (необязательно) обрезаются по помещениям и дверным проёмам.

## ceilings
`types`: `[{"id": "Т1", "short": "…", "desc": "…", "level": 2800, "kind": "bulkhead", "level_text": "+2,400"}]`;
`zones`: `[{"type": "Т2", "kind": "bulkhead|niche|cove", "name": "…", "poly": [[x,y],…], "bottom": 2400,
"overhead": true}]` — `overhead` показывает короб пунктиром на планах этажа.

## finishes
`types`: `[{"id": "О1", "desc": "…", "rgb": [r,g,b]}]`, `by_class`: `{"wet": "О2"}`,
`segments`: `[{"type": "О3", "a": [x,y], "b": [x,y]}]` — участки (фартук).

## elevations (развёртки)
```json
{"group": "Санузел", "room": "Санузел", "label": "А", "a": [x,y], "b": [x,y], "height": 2800,
 "tile": [600, 1200], "base": "tile|paint",
 "zones": [{"s0": 0, "s1": 998, "z0": 0, "z1": 1200, "mat": "tile|paint|apron"}],
 "fixtures": [{"name": "…", "poly": [[s,z],…], "glass": true, "outline_only": true}],
 "items": [{"type": "base|upper|tall|worktop|plinth|shelf|side|hob|appliance|led", "s0", "s1", "z0", "z1",
            "label": "…", "handle": "gola"}],
 "heights": [0, 100, 860, …], "module_chain": [0, 550, …], "labels": [{"text", "s", "z"}],
 "equipment": [["Варочная панель", "Р32, гр. 6"]], "notes": ["…"]}
```
- Вид всегда **из помещения**: `a` — левый конец стены для наблюдателя, `b` — правый (проверка ELEV_MIRRORED).
- `s` — расстояние от `a` вдоль стены, `z` — от чистого пола.
- Размеры модулей и высот — кратно 5 мм, без щелей < 15 мм (иначе предупреждение: исправить или пояснить).

## nodes (узлы)
`[{"num": 1, "type": "curtain_niche|shadow_gap|bulkhead", "title": "…", "params": {…}, "at": [x,y]}]` —
`at` — место выноски на плане потолков.

## Служебные пометки
- `"proposed": true` — элемент сделан `sda.py propose` по нормам (проектное предложение, подтверждается заказчиком).
- `"auto": true` у помещения — найдено по контуру стен, название нужно уточнить; `"check": true` у стены/проёма —
  взято автоматически из исходника, сверить.
- `_todo` в корне — черновик импортёра (fix смелее нормализует его: шаг 5 мм, оси, марки, двери).
- Журнал правок — `.sda_history/<имя>/` рядом с файлом (`sda.py history / undo / diff`).

## notes, overrides, sheets
- `notes`: `{"floors": {"add": ["…"]}}` — дополнить примечания листа; список — заменить.
- `overrides`: ручные позиции подписей, если автоматика не устроила: `tag_pos` {имя помещения: [x,y]},
  `furn_mark` {"Имя@cx,cy": [x,y]}.
- `sheets`: порядок / состав листов (ключи: cover, letter, general, measured, partitions, furniture, floors,
  ceilings, lighting, sockets, plumbing, finishes, elevations, openings).
