# Изменения

## 1.6.0 — стек модификаторов 3ds Max агент вычисляет сам
- **Без 3ds Max** (`importers/maxstack.py`, `importers/maxgeom.py`): стек модификаторов пересобирается так, как его
  пересобирает 3ds Max при открытии сцены — из сохранённых в .max данных. Edit Poly: перемещения, выдавливание,
  разрез, соединение рёбер и вершин, клонирование граней и рёбер, удаление, закрытие, «умное» выдавливание
  (насквозь и со сшивкой с соседними гранями), фаска вершин, фаска граней по полигонам; FFD 2×2×2 / 3×3×3 / 4×4×4,
  Symmetry, Chamfer (квад-фаска), TurboSmooth (как во вьюпорте), контур FloorGenerator. Нумерация вершин, рёбер и
  граней — как у MNMesh; каждый шаг сверяется с числами, которые 3ds Max сохранил (размеры выделений,
  смещения вершин, итоговые счётчики, габарит входа каждого модификатора). Не сошлось — «не проверено».
- В кафе Sherov: из 45 непроверенных объектов вычислены 38 — стены W4/W8/W9/W22 с дверными проёмами,
  короба-полки К-1/К-2 (оказались полками 1049×229×30, глубина растянута дизайнером на 109 мм), кресла, столы
  (журнальный стол поднят FFD с 452 до 719 мм), люстра (Ø920, а не Ø1130), стеллажи, облицовки колонн, двери,
  светильники, зоны пола П5/П6.
- TurboSmooth нумерует вершины как 3ds Max (каркас — центры граней — точки рёбер): правки Edit Poly поверх него
  повторяются напрямую. Барные столы кафе оказались двух высот: 4 шт. h 781 и 3 шт. h 558 (L-107).
- Запись дизайнера, совпавшая с несколькими изделиями модели, не размножает количество; размер и количество — по
  модели, расхождение — в отчёт и на эскиз; одинаковых названий у позиций нет (L-107).
- Полка на стене и низкий короб на полу больше не «журнальные столы» («Полка настенная», «Подиум»); сетки,
  вычисленные из стека, рисуются целиком (полки стеллажа вернулись на эскиз); пустой результат модификатора —
  только если сцена это подтверждает (L-107).
- Развёртки длинных стен — в масштабе, в котором помещаются (1:30, 1:40 …), не за рамкой листа (L-108).
- Длинная спецификация продолжается из полосы рядом с планом в правую колонку, а не в штамп (L-109); группа с
  невычисленной деталью — одно изделие; полка на стене на плане — своим контуром (L-107).
- Перегородка санузлов «по двери» — вывод агента на подтверждение, а не контур двери (L-106).
- Импорт: Editable Poly с «мёртвыми» вершинами читается верно; разобранная сцена освобождается из памяти перед
  сборкой альбома; большие сетки хранятся компактно.
- Уроки L-105 … L-109; тестов +26.

## 1.5.0 — сверка со сценой 3ds Max, DWG
- **Жёсткая сверка альбома со сценой** на каждой сборке (`audit`): каждый элемент знает свой объект сцены;
  элемент из невычисленной геометрии, стена не по размеру своего объекта (> 6 мм), архитектурный объект сцены,
  не попавший в альбом (стена, колонна, облицовка, короб, покрытие пола) — ошибки, статус `audit_errors`
  («не выдавать»), и на каждом листе — красная строка «НЕ СВЕРЕНО СО СЦЕНОЙ 3ds Max — НЕ ДЛЯ ВЫДАЧИ И
  СТРОИТЕЛЬСТВА»; стены, выведенные агентом, и прочие объекты сцены, которых нет в альбоме, — на проверку.
- **Модификаторы**: перемещения вершин Edit Poly повторяются на примитивах, сдвиг объекта целиком — тоже; что
  вычислить нельзя — честно «не проверено». В кафе Sherov исправлено: перегородка WC была длиннее на 580 мм,
  стена W11 — на 1520 мм (закрывала проём), стена WC W10 — не на месте на 200 мм.
- **Выгрузка 3ds Max** `scripts/max/sda_export.ms`: меши после всех модификаторов, скрытые / не рендерящиеся
  объекты, точные единицы — если лежит рядом со сценой, геометрия берётся из неё.
- **Облицовки и короба с плиткой**: слой плитки на колоннах и пилястрах, плитка бара и стены инсталляции — отделка
  своего основания; облицованные короба для труб (в т.ч. скошенные) — с настоящим контуром; плоскость на полу —
  зона покрытия.
- **Размеры**: оси, выведенные агентом из стен модели, и наружные цепочки по граням модели больше не рисуются —
  план образмерен в чистоте; в «Контрольных размерах» — названия помещений.
- **DWG**: рядом с PDF — `album.dwg` (LibreDWG, R2000), `album_edit.dxf` и архив `album_dwg.zip` (DWG + DXF +
  картинки листов), чертежи листов в модели расчленены; `sda.py dwg album.dxf`. На сервере LibreDWG собирается в
  образе. Проверка: DWG читается обратно, число объектов каждого типа совпадает с DXF; пустой вкладки Layout1 нет.
- **Формат плитки не придумывается**: зона покрытия без формата в модели — «уточнить», без швов и количества.
- **Компоновка**: правая колонка, которой не хватило места, продолжается рядом с планом / над развёртками, а не
  в штампе и не за рамкой.
- Уроки L-098 … L-104, тестов +26 (всего 211).

## 1.4.0 — всё из модели: короба, зоны пола, отделка, люстры и бра, развёртки зала, 3D моделями
- **Короба на плане перегородок** (`sdalbum/surfaces.py`): короб инсталляции за каждым подвесным унитазом (из модели
  или по нормам; верх — не выше низа окна, глубина ≥ 150, проверка глубины кабины), облицовки колонн, короба для
  стояков, каркас барной стойки, короб-основание скамьи на металлокаркасе с плиткой по фасаду и верху (эскиз скамьи
  ссылается на него). Выноски «К-n …, h=…», ведомость с площадью обшивки. Урок L-090.
- **Зоны пола из модели**: FloorGenerator (размер плитки из модификатора), сплайн-контур пола, зоны поверх основного
  покрытия со своим началом раскладки; цвет на тип, количество плиток; расхождение формата в имени материала —
  «подтвердить». Урок L-091.
- **Отделка стен из модели**, названия материалов — по файлам текстур сцены (Equipe Artisan Burgundy 132×132,
  Plaster 37, кирпич «лофт»): плитка только там, где она есть в модели. Урок L-092.
- **Люстры и бра**: на плане освещения (диаметр люстры, высоты), листы-эскизы светильников (виды по модели,
  отделка, крепление, низ подвеса). Урок L-093.
- **3D-вид общих данных — моделями сцены**, а не кубиками. Урок L-094.
- **План освещения**: связи — дерево соседей, привязки — цепочками по рядам светильников. Урок L-095.
- **Развёртки стен зала** с вывесками (текст и высота из сцены), бра, встроенной мебелью (контур по модели) и
  схемой развёрток. Урок L-096.
- Решения и общие примечания больше не копятся от сборки к сборке. Урок L-097.

## 1.3.0 — мебель индивидуального изготовления: ведомость и эскизы для цеха
- **Изделия из 3D-сцены** (`importers/scene_items.py`): мебель и декор собираются в изделия (группы, касающиеся
  объекты — основание скамьи с матрасами и подушкой; группа «стол + стулья» делится; два этажа стеллажа —
  одно изделие), одинаковые — одно изделие с количеством и местами установки; свет, растения, книги и декор на
  полках, техника, сантехника, двери, шторы, стены, рейки отбрасываются. Меши изделий сохраняются для чертежей.
- **Решения по изделиям** (`sdalbum/items.py`): что это (стол, журнальный стол, стул, кресло, диван, встроенная
  скамья, стеллаж, книжная полка, полка для пластинок) — по именам и геометрии; материалы по элементам; стеллаж
  вокруг колонн; помещение; марки М-1…; недостающие предметы — на план мебели (с маркой эскиза в спецификации).
- **Листы** (`sdalbum/sheets_items.py`): «Ведомость мебели индивидуального изготовления» (эскиз, габариты,
  материалы, количество, помещение, лист) и эскиз на каждое изделие: три вида по ГОСТ 2.305 в масштабе 1:5–1:50 с
  размерами, общий вид с выносками, материалы, характеристики, примечания для изготовителя.
- **Рендер** (`items3d.py`, `raster3d.py`): сглаживание TurboSmooth (Catmull-Clark), доски из плоскостей Shell,
  быстрый рендер плотных мешей, ограниченная триангуляция больших n-угольников.
- **Данные дизайнера** (`item_overrides`): названия, размеры, материалы, количество, покупные (`skip`),
  параметрические изделия без геометрии — световые вывески и декоративные панели; сохраняются при повторном импорте.
- Названия листов в штампе ужимаются до поля; цепочки размеров в листовом пространстве с реальными размерами.
- Уроки L-082…L-086, тесты: изделия сцены, сглаживание, виды, классификация, листы и данные дизайнера.

## 1.2.0 — агент-«старший архитектор»: решает сам, полный комплект листов, окна, аксонометрии, типографика
- **Решения вместо вопросов** (`sdalbum/senior.py`): назначение помещений по типу здания, оборудованию и смежности
  (обеденный зал, бар за стойкой, санузлы, тамбур, подсобное); потолки и свет — из модели дизайнера (открытый потолок,
  подвесной в санузлах, балки, карнизы штор, шинопроводы, споты, подвесы); вход наружу по СП 1.13130 с проверкой
  ширины; раковина персонала и водонагреватель (СанПиН); оснащение пустой подсобки; типы окон, витражей и дверей.
  Каждое решение с причиной — в report.md («Решения агента») и на листе «Общие данные».
- **Чтение сцены как у старшего**: стена, которой нет в модели, но на ней висит меню / стоит холодильник; ниша под
  умывальник; дверной блок в витраже; стойка из панелей с холодильными столами; колонны и перемычки из примитивов;
  декор не стена; битые габариты частей; подвесной унитаз; свет, балки, подвесные потолки сохраняются как данные.
- **Общественный интерьер**: керамогранит R10/R11, сервисные розетки зала, оборудование бара — розетки в корпусе
  стойки, кофемашина 32 А с водой и дренажом из пола, выключатели зала у персонала, ЩР в служебном помещении,
  групповые линии кафе (аварийное освещение, вывеска, кондиционеры, резерв).
- **Развёртки по умолчанию**: санузлы (плитка на всю высоту, приборы, короб инсталляции, выводы под высоким окном),
  стены с сантехникой в баре и подсобке; смежные мокрые помещения — одна группа с общим планом.
- **Новые листы**: «Аксонометрия» мокрых зон (собственный рендер с буфером глубины, раскладка плитки, приборы,
  открытые двери); «Окна и витражи» (модули, ригель, открывание по ГОСТ 23166, профиль, стеклопакет, узел
  примыкания по ГОСТ 30971); ведомость проёмов в два ряда, когда в один не помещается.
- **Типографика** (`sdalbum/typo.py`, QA TYPO_*): тире, «–» в диапазонах, «ёлочки», м², неразрывные числа с единицами
  и короткие предлоги; переносы делает агент.
- Уроки L-067…L-081, тесты: сцена-доказательства, решения старшего, типографика, буфер глубины.

## 1.1.1 — проверка на реальной сцене кафе (sherov cafeteria.max, 931 МБ)
- Единицы сцены — голосованием по дверям, сантехнике, мебели и стенам (сцена в см больше не читается как дюймы).
- Стены из 3D-сцены: плоские Plane/Box с Edit Poly, колонны, стены из частей вокруг окна (окно определяется),
  витражи (стена + окно на всю длину); шторы, двери, зеркала и мебель стенами не считаются; проёмы — по дверям и
  остеклению в разрывах; ложные «проёмы» вдоль стены убраны.
- Мебель и сантехника из сцены по именам объектов (унитаз, раковина, холодильник, столы, стулья, кресла...),
  обрезка габаритов по помещению; помещения называются по содержимому («Зал», «Санузел», «Кухня»...).
- Название объекта из имени файла («кафе «Sherov»»), щит ЩР для нежилых объектов, оси близких стен объединяются.
- Большие залы — двойные светильники вместо россыпи GU10; подвесы над каждым столом.
- Размещение: подписи в тесных местах уходят на выноску; самоисправление листа — ещё и для наложений и текста на
  стене. Тесты: 128. Уроков: 66.

## 1.1.0 — удобнее и умнее
- **Одна команда** `sda.py make <файл|папка> <папка> [--revit]` и `/album`: любой исходник (.max, DWG/DXF, векторный
  PDF, фото, project.json) → импорт → автоисправления → предложение по нормам → альбом → проверка → отчёт
  `report.md` с вопросами к заказчику. Повторный запуск сохраняет правки.
- **Импорт векторного PDF**: стены по заливкам, масштаб по размерным числам, оси по центрам несущих стен, тип
  каждого разрыва по нарисованному (окно / дверь / балконная дверь / проём); штриховки с «дырками» больше не
  превращаются в сплошной блок.
- **Автоисправление** `sda.py fix`: шаг 5 мм (кроме толщин материалов), точки на стену, сторона установки,
  ГВС слева, проходные/перекрёстные, РВ в санузлах, буквы развёрток, марки и типы проёмов, открывание дверей.
- **Проектное предложение по нормам** `sda.py propose` (только пустые разделы, с пометкой): свет по освещённости
  (СП 52), выключатели у входа со стороны ручки и у кровати, розетки по СП 256 и мебели, кондиционер, сантехвыводы,
  щит и группы, полы, потолки, отделка. На квартире в Ургенче выключатели встали там же, где у дизайнера (±15 см).
- **Правки словами**: `find / edit / undo / history / diff`, переименование помещения со всеми ссылками, сразу
  видно, что правка сломала или исправила; список изменений для заказчика с затронутыми листами.
- **Самоисправление листов**: проверка листа находит линию через подпись → лист перерисовывается с этой линией как
  препятствием; размеры не пишутся поперёк своих выносных линий; выносные линии не режут значки; надписи не
  уходят за видовой экран; строки легенды растут при переносе; линии управления многоместных групп — один раз.
  Предупреждений на эталоне: 30 → 7.
- Команды плагина: `/album`, `/album-edit`, `/album-revit`, `/album-learn`.
- Тесты: 122 (было 72). Уроков: 61 (было 48).
