# Изменения

## 1.1.1 — проверка на реальной сцене кафе (sherov cafeteria.max, 931 МБ)
- Единицы сцены — голосованием по дверям, сантехнике, мебели и стенам (сцена в см больше не читается как дюймы).
- Стены из 3D-сцены: плоские Plane/Box с Edit Poly, колонны, стены из частей вокруг окна (окно определяется),
  витражи (стена + окно на всю длину); шторы, двери, зеркала и мебель стенами не считаются; проёмы — по дверям и
  остеклению в разрывах; ложные «проёмы» вдоль стены убраны.
- Мебель и сантехника из сцены по именам объектов (унитаз, раковина, холодильник, столы, стулья, кресла...),
  обрезка габаритов по помещению; помещения называются по содержимому («Зал», «Санузел», «Кухня»...).
- Название объекта из имени файла («кафе «Sherov»»), щит ЩР для нежилых объектов, оси близких стен объединяются.
- Большие залы — двойные светильники вместо россыпи GU10; подвесы над каждым столом.
- Размещение: подписи в тесных местах уходят на выноску; самоисправление листа — ещё и для наложений и текста на
  стене. Тесты: 128. Уроков: 66.

## 1.1.0 — удобнее и умнее
- **Одна команда** `sda.py make <файл|папка> <папка> [--revit]` и `/album`: любой исходник (.max, DWG/DXF, векторный
  PDF, фото, project.json) → импорт → автоисправления → предложение по нормам → альбом → проверка → отчёт
  `report.md` с вопросами к заказчику. Повторный запуск сохраняет правки.
- **Импорт векторного PDF**: стены по заливкам, масштаб по размерным числам, оси по центрам несущих стен, тип
  каждого разрыва по нарисованному (окно / дверь / балконная дверь / проём); штриховки с «дырками» больше не
  превращаются в сплошной блок.
- **Автоисправление** `sda.py fix`: шаг 5 мм (кроме толщин материалов), точки на стену, сторона установки,
  ГВС слева, проходные/перекрёстные, РВ в санузлах, буквы развёрток, марки и типы проёмов, открывание дверей.
- **Проектное предложение по нормам** `sda.py propose` (только пустые разделы, с пометкой): свет по освещённости
  (СП 52), выключатели у входа со стороны ручки и у кровати, розетки по СП 256 и мебели, кондиционер, сантехвыводы,
  щит и группы, полы, потолки, отделка. На квартире в Ургенче выключатели встали там же, где у дизайнера (±15 см).
- **Правки словами**: `find / edit / undo / history / diff`, переименование помещения со всеми ссылками, сразу
  видно, что правка сломала или исправила; список изменений для заказчика с затронутыми листами.
- **Самоисправление листов**: проверка листа находит линию через подпись → лист перерисовывается с этой линией как
  препятствием; размеры не пишутся поперёк своих выносных линий; выносные линии не режут значки; надписи не
  уходят за видовой экран; строки легенды растут при переносе; линии управления многоместных групп — один раз.
  Предупреждений на эталоне: 30 → 7.
- Команды плагина: `/album`, `/album-edit`, `/album-revit`, `/album-learn`.
- Тесты: 122 (было 72). Уроков: 61 (было 48).

## 1.0.0
- Движок `sdalbum`: 14 типов листов + развёртки и узлы; размещение всех надписей через реестр занятости;
  размерные цепочки по ГОСТ 2.307 (короткие — ступенькой, без шумовых отрезков); подписи с подложкой поверх линий.
- QA листов: наложения по реальным глифам, текст на стенах, штамп/рамка, таблицы на чертеже, обрезка видовыми экранами.
- Проверка данных: 50+ правил (геометрия, привязки, высоты, развёртки, двери и их «рука», полы, потолки, модули,
  шум 3D-модели, многоместное управление светом, горячая вода слева).
- Площади помещений в чистоте (проём-горловина не входит), итоги таблиц = сумма строк.
- Блок «Вопросы к заказчику» на листе «Общие данные» (конфликты дверей и мебели, спорные проёмы).
- Импорт: 3ds Max (.max без 3ds Max), DWG/DXF (стены, проёмы, помещения), руководство по PDF/фото.
- Revit: генератор pyRevit/Dynamo, проверяется на макете Revit API.
- Тесты: 72 (модель, листы, импорт, Revit, уроки, полная регрессия двух эталонов).
- База опыта: 48 уроков со стражами (в т.ч. 19 — по независимой проверке альбома); скилл improve-agent.
